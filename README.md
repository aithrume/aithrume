## 안녕하세요 👋

부동산학을 기본으로 AI 기술과 빅데이터 기술을 활용하여 부동산 관련 데이터를 분석하고,
이를 활용하는 방법을 공부하고 있습니다.

### 🌐 [aithrume.github.io](https://aithrume.github.io) — 데이터 분석 포트폴리오

공공·민간 데이터를 직접 받아 가공하고, 지도와 그래프로 시각화합니다.

| 📈 경제 지표 | 🏢 부동산 지도 |
|---|---|
| [GDP 성장률](https://aithrume.github.io/gdp.html) | [KB 주간 아파트 시세](https://aithrume.github.io/kb.html) |
| [금리 추이 · 주요국 정책금리](https://aithrume.github.io/rates.html) | [아파트 실거래](https://aithrume.github.io/trade.html) |
| [주택 공급 · 미분양](https://aithrume.github.io/supply.html) | [외국인 주택 소유](https://aithrume.github.io/foreign.html) |

🏔️ 취미: [등산 GPX 기록](https://aithrume.github.io/hiking.html) · [여행 지도](https://aithrume.github.io/travel.html) · [게임](https://aithrume.github.io/games.html)

### 🛠️ 사용하는 것

- **데이터 수집·가공:** Python — 한국은행 ECOS, 통계청 KOSIS, 한국부동산원 R-ONE, 공공데이터포털 API
- **시각화:** JavaScript · SVG (지도·그래프 직접 구현), Leaflet
- **자동화·배포:** GitHub Actions, GitHub Pages
